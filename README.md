# Productivity Hub AI

Build a Modern AI Workplace Productivity Assistant

Create a modern, responsive, professional and presentation-ready SaaS web application called:

AI Workplace Productivity Assistant

The application should help professionals automate and simplify common workplace tasks using AI.

The final product must feel like a real commercial SaaS platform, not a basic prototype. It should demonstrate strong problem relevance, prompt engineering, functionality, innovation, responsible AI practices and professional UI/UX.

1. Core Purpose

The application is an all-in-one AI workplace productivity assistant.

It should help users:

Write professional emails

Summarize meetings

Organize and prioritize tasks

Conduct structured research

Ask questions through an AI chatbot

The main value proposition is:

Save time on repetitive workplace tasks so professionals can focus on higher-value work.

2. Required AI Features

The application must include these five core features:

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner

AI Research Assistant

AI Chatbot Interface

Each feature must have its own dedicated page accessible from the sidebar.

13. Structured AI Prompt Engineering

Prompt engineering is a major evaluation criterion.

Use structured, high-quality prompts for every AI feature.

Do NOT use vague instructions.

Each AI prompt should define:

Role

What the AI is acting as.

Task

Exactly what the AI needs to accomplish.

Context

The information provided by the user.

Constraints

Tone, length, audience, accuracy and limitations.

Output Format

The exact structure expected from the AI.

Example:

Role:

"You are a professional workplace communication assistant."

Task:

"Generate a professional email based on the user's instructions."

Context:

"{user_input}"

Requirements:

Use professional language.

Be concise.

Preserve the user's intended meaning.

Do not invent facts.

Do not add information that was not provided.

Use appropriate formatting.

Output:

Subject

Email Body

Apply this structured approach to:

Email generation

Meeting summarization

Task planning

Research

Chatbot responses
